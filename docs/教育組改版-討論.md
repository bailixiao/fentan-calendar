# 分壇行事曆大改：分壇教育組（討論紀錄）

> 還在討論，還沒動程式。定案後整理進 `docs/spec.md`，再開始改。

## 已經決定的（2026-10-15）

- **只做分壇教育組**。總務、道務先不要。
- 現在系統裡的總務、道務活動（含匯入的 115 年度分配表、各區輪值）**全部刪掉**。設計定案後，先下載備份再刪。
- **不要行事曆的模樣**（不要年、月、週那種格子）。
- **主畫面要乾淨**：平常只看得到「現在可以報名的那幾個班」。
- 一整年會有固定兩三種課程，事先規劃好。
- 管理者在後台**隨時可以加新活動**，開放給大家報名。

## 第一輪回覆（2026-10-15）

1. 課程：**高大班、青少年班**，都是**兩個禮拜一堂**。
2. 每一堂要記：時間、地點、**主題、講師、課程內容**。
3. 日期有固定規則：**隔週六**上一次課。
4. 分工：還不確定，**先空著**（這一版不做分工）。
5. 誰會看：**所有家人**都看得到這個報名 App。
6. 上課**要點名**。

## 第二輪回覆（2026-10-15）

1. **每一堂各自報名**。
2. **家人自己**報，或**各區組長**幫忙報。
3. 報名填：**姓名、區**。
4. 報名名單**公開**。
5. **幹部用手機勾「到／請假／缺席」**。
6. 一期＝**一整年**。

## 設計初稿（等確認）

**主畫面（家人看的）**：沒有行事曆格子。上面是班的卡片（高大班、青少年班、臨時活動），每張寫「下一堂：日期、主題、講師、已報名 N 人」和「報名」按鈕。點進去：班的介紹＋一整年每一堂（已經上過的收起來）。

**報名（每一堂）**：填姓名、選區，按報名（不用登入）。名單公開、照區排。這支手機報的可以自己取消；組長登入後可以幫自己區的人報名、取消。報名截止：預設上課前一天（每堂可以改）。

**點名（幹部）**：「點名」帳號（總管理者設密碼）。上課當天打開那一堂：報名的人照區列出，每人一排「到／請假／缺席」；沒報名但來了的可以當場加。點完有統計（到 N、請假 N、缺席 N），之後可以看每個人一整年的出席。

**後台（總管理者）**：建一個班（名稱、顏色、介紹、預設時間地點），選第一堂日期，自動排出一整年隔週六的每一堂；每堂可以填主題、講師、課程內容，可以改日期、停課。臨時活動＝只有一堂的班，隨時加。

## 第二輪問題（報名、點名的細節）

1. 報名是**報整期**（報一次，之後每堂都在名單上、上課點名），還是**每一堂各自報名**？
2. 誰來報名：**家人自己**（學員或家長）報，還是**各區組長**幫忙報？
3. 報名要填哪些資料？（姓名、區、年級、家長電話⋯）
4. 報名名單要公開給大家看嗎？（青少年建議只給幹部看）
5. 誰點名、怎麼點：幹部用手機勾「到／請假／缺席」，還是掃名牌 QR（像敦化班）？
6. 一期多長？（上半年、下半年？一整年？）
